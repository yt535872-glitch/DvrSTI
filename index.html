Tableau très simple des éléments HTML et CSS — شرح سهل بالفرنسية والعربية

À retenir / تذكّر:
HTML sert à créer le contenu de la page. — HTML يُستعمل لإنشاء محتوى الصفحة.
CSS sert à changer l'apparence de la page. — CSS يُستعمل لتغيير شكل الصفحة.
Élément / العنصرExplication très simple / شرح مبسّط
<h1>
Français : Affiche le titre principal de la page.
العربية: يعرض العنوان الرئيسي للصفحة.
<h3>
Français : Affiche un titre de niveau 3, pour un sous-titre.
العربية: يعرض عنوانًا فرعيًا من المستوى الثالث.
<p>
Français : Écrit un paragraphe.
العربية: يكتب فقرة نصية.
<mark>
Français : Surligne un texte.
العربية: يُظلّل نصًا لإبرازه.
<br>
Français : Passe à la ligne.
العربية: ينتقل إلى سطر جديد.
<div>
Français : Regroupe plusieurs éléments dans un bloc.
العربية: يجمع عدة عناصر داخل كتلة واحدة.
<header>

العربية: ينشئ رأس الصفحة أو القسم.
<nav>
Français : Regroupe les liens de navigation.
العربية: يجمع روابط التنقل بين الصفحات.
<section>

العربية: يجمع عناصر تتحدث عن الموضوع نفسه.
<main>

العربية: ينشئ رابطًا لصفحة أخرى. و`href` يحدد الصفحة المطلوبة.
target="if"

العربية: يعرض صفحة داخل الصفحة الحالية. `src` يحدد الصفحة و`name` يعطي إطار iframe اسمًا.

العربية: يجمع الأسطر التي تحتوي على البيانات.

العربية: ينشئ خلية عنوان في الجدول.
<td>

العربية: ينشئ خلية عادية في الجدول.

<ol>
Français : Crée une liste numérotée.
العربية: ينشئ قائمة مرتبة بالأرقام.
type="I"

العربية: مع `<ol>` يستعمل الأرقام الرومانية: I وII وIII…
start="5"
Français : Fait commencer la liste au numéro 5.
العربية: يجعل القائمة تبدأ بالرقم 5.
reversed
Français : Affiche les numéros dans l'ordre décroissant.
العربية: يعرض أرقام القائمة تنازليًا.
<ul>
Français : Crée une liste avec des puces.
العربية: ينشئ قائمة بعلامات نقطية.

Français : Utilise des cercles vides comme puces.
العربية: يستعمل دوائر فارغة كعلامات للقائمة.
<li>

<details>
Français : Crée une zone que l'on peut ouvrir et fermer.
العربية: ينشئ مساحة يمكن فتحها وإغلاقها لإظهار أو إخفاء المعلومات.
<summary>
Français : Crée le titre cliquable de `<details>`.
العربية: ينشئ العنوان الذي نضغط عليه داخل `<details>`.
<img src="..." alt="...">
Français : Affiche une image. `src` indique le fichier et `alt` donne un texte si l'image ne s'affiche pas.
العربية: يعرض صورة. `src` يحدد ملف الصورة و`alt` يقدم نصًا بديلًا إذا لم تظهر.
<figcaption>
Français : Ajoute une légende à une image.
العربية: يضيف وصفًا أو تعليقًا أسفل الصورة.
<video controls src="...">
Français : Affiche une vidéo. `controls` montre les boutons lecture, pause et volume.
العربية: يعرض فيديو. و`controls` يُظهر أزرار التشغيل والإيقاف والصوت.
<audio controls src="...">

العربية: يسمح بتشغيل ملف صوتي مع أزرار التحكم.

العربية: ينشئ استمارة لإدخال المعلومات وإرسالها.

Français : Indique où envoyer les données du formulaire.
العربية: يحدد الصفحة التي تُرسل إليها بيانات الاستمارة.
method="get"
Français : Envoie les données dans l'adresse URL.
العربية: يرسل البيانات ضمن رابط الصفحة (URL).

العربية: يعرض اسم خانة الإدخال. يجب أن تتطابق قيمة `for` مع `id` الخاص بالخانة.

Français : Crée une case pour écrire du texte.
العربية: ينشئ خانة لكتابة نص.
<input type="number">

العربية: ينشئ خانة لإدخال رقم.
min="1" et max="5"

العربية: يحددان أصغر قيمة وأكبر قيمة مسموحتين.
required

العربية: يجعل ملء الخانة إجباريًا.
placeholder="nom?"

العربية: يسمح باختيار عدة إجابات.
<input type="submit">

العربية: ينشئ زرًا لإرسال الاستمارة.

العربية: يعيد خانات الاستمارة إلى حالتها الأولى.

<textarea>

<fieldset>
Français : Regroupe des champs du formulaire dans un cadre.
العربية: يجمع خانات الاستمارة داخل إطار.
<legend>

<button>

style="..."

color

padding

border
Français : Ajoute un cadre autour de l'élément.

border-radius

position: fixed
Français : Fixe l'élément à l'écran : il reste au même endroit pendant le défilement.
العربية: يثبت العنصر على الشاشة ويبقى في مكانه عند تمرير الصفحة.
position: sticky
Français : L'élément défile normalement puis reste collé quand il atteint la position définie.

left

#message ou #msg
